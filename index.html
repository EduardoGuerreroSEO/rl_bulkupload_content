Required Excel Headers

Name files by source language: EN.xlsx, FR.xlsx, DE.xlsx, ES.xlsx, IT.xlsx, NL.xlsx, PT.xlsx, PL.xlsx, SE.xlsx for EU; EN.xlsx or AR.xlsx for ME. Only the first worksheet is read.

EU uses the original country-code and £ symbol replacements. ME uses {{MARKET_BRAND}} or the original Saudi brand token. Amounts are not converted.

Output contains page title and description only. Empty cells are omitted, keeping existing values. Import through Content → Import & Export, using UPDATE and the intended site/library.
